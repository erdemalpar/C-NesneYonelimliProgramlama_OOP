public interface IKaydedilebilir { void TescilEt(); }
public abstract class Tasinmaz : IKaydedilebilir {
private double _yuzolcumu; // Field (Korumalı Veri)

public static int ToplamSayi = 0; // Static (Tüm Sicil İçin Tek)
public Tasinmaz(string no) { // Constructor (Yeni Kayıt)
this.KimlikNo = no;
}
public virtual void BilgiYazdir() { ... } // Virtual Metot
}
// 2. Türetme ve Özelleştirme
public sealed class Parsel : Tasinmaz { // Kalıtım & Sealed (Son Birim)
public Parsel(string pNo) : base(pNo) { // base Kullanımı
Tasinmaz.ToplamSayi++;
}
public override void BilgiYazdir() { // Override (Özelleştirme)
Console.WriteLine("Parsel Detayları Yazdırıldı.");
}
}

01. KADASTRO OOP TEMELLERİ

Sınıf vs Nesne (Pafta vs Arsa) Sınıf, tapudaki boş bir tescil şablonudur (Blueprint). Nesne ise o şablona göre tescil edilmiş, konumu ve alanı belli olan GERÇEK bir parseldir.
Kapsülleme (Alan Koruması) Taşınmazın yüzölçümü doğrudan değişemez (private). Sadece 'Cins Değişikliği' veya 'İfraz' gibi yasal yollarla (Public Property/Getter-Setter) güncellenebilir.

02. KADASTRODA SOLID PRENSİPLERİ

S Single Responsibility

Parsel sınıfı sadece geometrik ve mülkiyet verisini tutar. Vergi borcu hesaplama veya İmar durumu sorgulama işini başka sınıflar yapar.

O Open/Closed

Sisteme 'Zeytinlik' veya 'Sit Alanı' gibi yeni taşınmaz tipleri eklemek için mevcut 'Tasinmaz' kodunu değiştirmeyiz, yeni sınıflar türetiriz.
