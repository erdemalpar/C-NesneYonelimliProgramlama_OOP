// Kadastro Hiyerarşisi
public interface ITapulu { void SicilYazdir(); }
public abstract class Tasinmaz : ITapulu {
public string Il, Ilce, Mahalle;
private int _ada, _parsel; // Gizli veriler
public Tasinmaz(string il, string ilce) {
this.Il = il; this.Ilce = ilce;
}
}
// Miras ve Polimorfizm
public class Yapı : Tasinmaz {
public int KatSayisi;
public override void SicilYazdir() { // Override işlemi
Console.WriteLine("Bina Tescili...");
}
}

REALİSTİK VERİ MODELİ

Kadastroda bir nesne (Object), sadece bir isimden ibaret değildir. İl, İlçe, Mahalle gibi hiyerarşik bilgilerden oluşan **Karmaşık Tip (Complex Type)**'lara sahiptir.

İl/İlçe/Mahalle: Hiyerarşik Yapı
Ada/Parsel: Kimlik Bilgisi (ID)
Bağımsız Bölüm: İç İçe Nesneler (Composition)

SOLID DETAYI

**OCP:** Yeni bir "Mera" veya "Orman" tipi eklemek istediğimizde mevcut Taşınmaz kodunu değiştirmiyoruz; yeni sınıf türetiyoruz. Sistemimiz tescili otomatiğe bağlar.
