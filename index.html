public class Tasinmaz {
public string Il, Ilce, Mahalle;
public int Ada, Parsel;
}

// Miras Zinciri (Inheritance)
public class Arsa : Tasinmaz { ... }
public class Bina : Arsa { ... }
public class Bolum : Bina { ... }
// OOP'de İlişkisellik (Association)
// Bir Bağımsız Bölüm, içine doğduğu Binanın tüm lokasyon verisini base anahtarıyla miras alır.

VERİ TUTARLILIĞI (DATA CONSISTENCY)

OOP'de nesneler birbirine sıkı sıkıya bağlıdır. Bir **Bağımsız Bölüm** oluşturulduğunda, o bölümün hangi **Bina**'ya, o binanın hangi **Parsel**'e ait olduğu hiyerarşik olarak korunur.

DERİN MİRAS PAZARLIĞI

C#'ta `base` anahtar kelimesi ile alt sınıf (Bolum), üst sınıfların (Bina -> Arsa -> Tasinmaz) constructor'larını tetikleyerek veriyi yukarıdan aşağıya doğru silsile yoluyla "devralır".
